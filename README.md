# DOL-TemplePendantGuarantee
在神殿祈祷室祈祷时，是否总觉得那些特殊的超自然事件可望而不可即？原版中这类事件由随机数 $rng 决定，只有摇出极高的数值（神圣吊坠需 100、石头吊坠需 99、黑暗吊坠需 98，或摇出 91 以上且佩戴对应吊坠）才触发，概率极低。 本 Mod 让佩戴吊坠时必定触发对应的超自然事件： 佩戴 神圣吊坠（holy pendant） → 随机数锁定为 100； 佩戴 石头吊坠（stone pendant） → 随机数锁定为 99； 佩戴 黑暗吊坠（dark pendant） → 随机数锁定为 98； 未佩戴任何吊坠时，完全保持原版随机。 设计细节： 仅在你确实佩戴对应吊坠时生效，不改变其他任何祈祷结果； 无需开关，进入祈祷流程即自动生效； 不改动存档数据，移除 Mod 后立即恢复原版概率。
